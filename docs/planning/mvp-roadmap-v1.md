# AnimeUta 开发路线

## 已进入基线

- TypeScript Fastify 单体、SQLite WAL 与顺序迁移。
- 首位 owner、邀请注册、会话刷新/撤销、角色与用户管理。
- 智能文件导入、音频标签/内嵌封面/内嵌歌词、ZIP 匹配预览。
- 私有签名音频流、Range、全局播放器、队列、循环、音量记忆与 Media Session。
- LRC/SRT/TXT、双语歌词、ruby、罗马音、逐句编辑和内部滚动。
- 持久 AI 任务、OpenAI-compatible provider、失败重试与额度。
- ACG 元数据、别名搜索和学习曲库检索。
- 歌曲分词、双向学习卡、四级评分、间隔调度、学习统计和设置。
- Tauri Windows 客户端以及 Capacitor Android/iOS 工程。

## 基线收口

完整状态与发布门槛见 [V1 需求总览与验收矩阵](requirements-matrix-v1.md)。当前按以下顺序收口：

1. 配置正式外部 OpenAI-compatible 文本与转写 API，用不同混音和演唱方式的真实歌曲完成六类任务验收，并保留人工修正流程。
2. 在浏览器中继续做简体中文、日文和英文视觉回归；词条一致性、静态引用和裸文案已纳入自动验证。
3. 用真实内容继续验收 ACG 详情、关联编辑、别名搜索与版本聚合。
4. 在 Android 真机验证文件选择、播放、后台控制和安全区；iOS 在 macOS/Xcode 环境验证。
5. 完成 Windows 安装/升级回归、Android 设备回归和发布前完整备份恢复演练。

## 后续增强

- 更可靠的日语形态分析器或词典，减少 LLM 分词依赖。
- 基于真实复习数据校准间隔调度参数和趋势图。
- Android/iOS 系统分享目标。
- 阿里云 OSS 私有桶存储适配和临时签名 URL。
- 跟唱、录音对比和发音反馈。

## 不在范围

未授权音源抓取、海量公共曲库、弹幕、重社交、秒杀、GEO、Redis、Kafka、分布式锁和微服务。
