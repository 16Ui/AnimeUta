## 外部环境验收

以下项目不能在当前 Windows 主机上伪造为已通过：

- 外部 AI：当前代码和运行配置已切换为外部 OpenAI-compatible 文本与转写 API，本地开发启动不再启动 Ollama 或 Whisper。六类任务的持久化、结构校验、失败重试和原子写回已有自动化覆盖；由于尚未填写外部 API 地址、模型和 Key，供应商连通性及真实歌曲结果需要在凭据配置后重新验收。此前本地模型结果仅作为历史链路证据，不再代表当前运行供应商。
- Android 真机：已安装并校验 Android 命令行工具、SDK 36 与 JDK 21，`gradlew assembleDebug` 构建成功；debug APK 通过 v2 签名，并核对包名 `app.animeuta.mobile`、minSdk 24、targetSdk 36、debug 标记和 SHA-256 `01885e00c0181fffcc0f10581beacddc21912d5dbcfe89f1ff2b44a8949fd4d7`。明文 HTTP 的网络访问与 WebView 混合内容仅在可调试应用中放开，`install-android.ps1` 会通过 ADB 反向映射本机后端、安装并启动应用；ADB 当前没有已连接设备，仍需验证系统文件选择、播放、后台恢复、锁屏和耳机控制。
- iOS 真机：必须在 macOS、Xcode 和签名环境中构建与验证。
- 原生后台播放：Media Session 已在 Web 实现；Android/iOS 的锁屏、通知栏、耳机按键与系统回收行为必须在真机验收。
