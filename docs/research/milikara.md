## 定位与功能

原 KiraKara 仓库跳转至 MiliKara，README 说明从 v1.1.0 改名。它是日语卡拉 OK 自动对齐和视频制作工具，不是在线音乐搜索下载器，也不等同于同名 KiraKara player。

根据官方 README，可输入音视频、背景图和 LRC 或歌曲链接，进行规则/可选 AI 注音、人声分离、假名拍级对齐，再生成逐字扫光字幕视频。支持翻译显示、罗马音、演唱者分色、任务排队，以及人工试听、微调和局部重跑。提供本地 HTTP API；具体端点、鉴权与数据格式本次未验证。以上是作者文档描述，不是我们的运行验收结果。

来源：[项目 README](https://github.com/BilyHurington/MiliKara#readme)。

## 对 AnimeUta 的建议（工程判断）

优先评估拍级时间轴、读音校验与修正、局部重算。视频导出可作为后续独立功能，不应替代现有播放器。先用少量授权歌曲比较长前奏、重复副歌、长音和促音的对齐结果，再决定接入。

建议计算任务在本地较强电脑或独立工作节点执行，云端保留任务管理、音乐播放与结果存储。依据上述模型依赖，不建议未经实测就把分离、对齐、视频编码一起部署到现有小规格云服务器。CPU 可运行不代表延迟、内存峰值或并发满足需求；本次没有测得最低内存、显存、耗时和准确率。

集成前需进一步核对 API 契约、网络暴露及身份认证、任务取消/重试、模型许可，并测试结果能否映射到 AnimeUta 的逐词/逐拍歌词结构。当前只完成调研，没有接入或安装 MiliKara。
