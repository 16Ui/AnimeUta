# AnimeUta 领域模型

## 核心闭环

1. 用户从设备导入一首自己拥有的音频，可附歌词、封面或 ZIP。
2. 系统读取音频标签并生成可修改预览。
3. 歌曲进入用户私人曲库；用户可主动申请共享给受邀好友。
4. 歌词经过转写、翻译、注音、对轴、批注和分词。
5. 用户按词元选择单词，加入一个或多个词库。
6. 系统生成日到中、中到日卡片并按评分安排复习。
7. 学习卡保留歌曲、歌词句和时间位置，可回到上下文播放。

## 音乐领域

`Song` 是可播放对象；`Artist`、`Work`、`Album`、`Creator`、`Character`、`VoiceActor`、`Publisher` 与 `Label` 构成 ACG 检索上下文。主要实体拥有独立资料、图片与别名，并且只有在当前用户能看到至少一首关联歌曲时才可发现。`SongVersionGroup` 聚合同曲的 Full、TV Size、Instrumental、Cover 和变奏。

## 歌词领域

`Lyric` 保存歌曲的当前歌词内容，`LyricLine` 是时间轴与双语展示单元，`LyricToken` 将句子中的出现位置连接到去重后的 `Lexeme`。`LyricAnnotation` 保存个人学习解释。歌词和批注在用户自己的学习空间内直接编辑，不设置投稿审核队列。

## 学习领域

`StudyDeck` 属于单个用户。`StudyCard` 固定一个词元、背诵方向和来源上下文。揭晓后用户以忘记、困难、良好、简单评分，调度器更新稳定度、难度与到期时间；`ReviewLog` 保留每次决策。

## 共享边界

私人曲库不是公共投稿站。用户导入默认进入自己的曲库；如需与好友共享，由所有者直接维护可见范围，不设置内容审核板块。账号、学习进度、收藏、歌单和历史始终按用户隔离。
