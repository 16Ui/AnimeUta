# AnimeUta 桌面歌词实用功能调研

日期：2026-10-24。结论：基础显示功能已经比较齐全，下一步应优先解决“看得全、不切窗也能操作、窗口不会丢”，而非继续堆装饰或学习模块。

## 范围与证据

- 以当前工作区代码为准，不把旧文档或已打包版本当作现状；本次仅静态阅读和官方资料调研，未启动客户端，原生穿透、多屏和快捷键行为未实测。
- 已阅读桌面歌词页、偏好 hook、窗口通信、全局播放器、播放 store、歌曲详情页及 Tauri 初始化和窗口配置。下文“缺少”指这些代码中未发现实现，不代表已对所有运行环境做验证。

## 官方对照

- **Apple Music Windows MiniPlayer**：小窗口支持播放操作、音量、进度、歌词和待播列表，悬停显示控件。启示是减少切回主窗口，不是照搬封面布局。[Apple 官方指南](https://support.apple.com/en-gb/guide/music-windows/mus71d7dcfce/windows)
- **LX Music**：官方默认设置声明了暂停/全屏隐藏、位置尺寸、字体颜色与透明度、长句省略策略，以及翻译显示、倍速与保音高选项。这里只确认源码存在对应配置，不声称所有平台表现一致。[官方设置源码](https://raw.githubusercontent.com/lyswhut/lx-music-desktop/master/src/common/defaultSetting.ts)
- **LyricsX**：官方说明支持字体/颜色/位置调整、菜单校准、双击歌词定位和歌词导入导出；产品面向 macOS，仅借鉴交互，不推断 Windows 兼容性。[官方仓库 Features](https://github.com/ddddxxx/LyricsX#features)
- **VLC**：官方文档说明可用书签定位歌曲片段，以及跳转指定时间。它支持“快速回听”的需求方向，但不据此声称本页证明了 A–B 循环。[VideoLAN 官方播放指南](https://docs.videolan.me/vlc-user/desktop/3.0/en/basic/playback.html)

## 建议优先级

以下均为结合本地缺口作出的产品建议，并非竞品功能清单照抄。P0 为下一批优先，P1 为随后，P2 为轻量增强；编号亦为建议顺序。

| 顺序 | 建议与现有差异 | 最小范围与验收 | 依据 |
| --- | --- | --- | --- |
| 1 · P0 | **长句完整显示**：四条文字轨道均使用 `truncate`；虽然可放大窗口，仍无完整阅读策略 | 优先提供有界两行换行或横向滚动；原文、翻译分别处理，保留假名空间。最窄允许窗口、48 号字、长日文/长译文都能读全，控件不被挤走；避免每句变化都移动窗口 | 桌面歌词页；LX 的省略/滚动相关配置仅作对照 |
| 2 · P0 | **浮窗播放操作与快捷入口**：主播放器已有，浮窗只有设置/锁定/关闭；窗口通信目前主要传状态，没有播放命令通道 | 悬停提供播放/暂停、上一首/下一首、返回当前歌曲页；再补可配置全局显隐/解锁快捷键并提示冲突。主窗口最小化仍能操作，锁定穿透逻辑保持有效；复用主播放器，不创建第二音频实例 | 全局播放器、窗口逻辑、Tauri 初始化；Apple MiniPlayer |
| 3 · P0 | **窗口记忆、找回与避让**：当前启动居中且隐藏，未发现位置尺寸持久化、多屏恢复或自动隐藏逻辑；`isPlaying` 已传入但未用于隐藏 | 本机保存位置/宽度，提供“恢复到当前屏幕”；拔掉副屏后不能留在屏幕外。暂停隐藏、全屏避让做独立可选项；先完成记忆/找回，再验证全屏检测。锁定状态下仍有找回入口 | 窗口配置、窗口逻辑、Tauri 初始化；LX 窗口/隐藏配置 |
| 4 · P1 | **翻译独立开关与显示偏好分层**：译文没有用户开关；浮窗与详情页共享字号、假名、罗马音，背景仅开/关 | 增加译文开关，允许仅原文或原文+假名；浮窗字号可独立覆盖，保留“跟随统一设置”。颜色/背景透明度提供少量高对比预设即可；在浅色网页和深色桌面都可读，关闭翻译不影响其他轨道 | 偏好 hook、桌面歌词页、详情页；LX 显示配置、LyricsX 外观选项 |
| 5 · P1 | **歌词状态、重试与缓存兜底**：已有加载/空歌词和偏好保存错误；歌词请求错误没有单独分支，可能落到“无歌词”；快照有 `sentAt` 但未判断过期 | 区分加载失败、确实无歌词、没有逐句时间、播放器失联；失败可重试，失联不能一直冒充正在播放。已成功取得的歌词/偏好做按账号与服务端隔离的本地缓存，标明缓存状态；这不等于承诺离线音频播放 | 桌面歌词页的 `lyricsQuery` 分支、窗口快照、偏好 hook；属于本地代码直接暴露的可用性缺口 |
| 6 · P1 | **普通用户个人时间微调**：共享校准已实现，但只有上传者/管理员可改，且浮窗没有入口 | 浮窗提供提前/延后/重置；个人设备补偿与共享歌词校准明确分开，普通用户调整不影响别人。定义两种偏移叠加规则，换歌、重新打开浮窗均一致，避免未授权调用现有共享写接口 | 详情页权限判断及广播、桌面歌词偏移计算；LyricsX 菜单校准 |
| 7 · P1 | **当前句重听，随后句循环与保音高慢放**：已有按句定位和整曲循环，未发现句段循环/倍速状态；Media Session 速率固定为 1 | 先提供“重听本句”，再做单句循环和 0.75/0.9/1 倍。区间结合 `startMs`、下一句或有效结束时间及偏移；无时间数据禁用，切歌清除循环，拖进度可退出。只服务日常听清和跟唱，不引入练习评分 | 播放 store、全局播放器、详情页；LyricsX 按句定位、VLC 回听定位、LX 倍速/保音高配置。句循环是本项目推导建议 |
| 8 · P2 | **当前句复制与返回原有查词页**：查词/学习卡已有，但桌面歌词文本不可选择，也无当前句操作入口 | 解锁后提供复制原文/原文+译文、打开当前歌曲并定位当前句；复用既有释义和加卡界面，不把浮窗扩成学习工作台。锁定时不拦截底层点击 | 桌面歌词页 `select-none`、详情页现有词汇交互；属于连接已有功能的项目内建议 |

## 建议交付边界

先做 1–3，再做 4–6；7 先上线单次重听，再判断是否需要循环/慢放，8 最后补。暂停/全屏自动隐藏不应默认开启后让用户误认为窗口丢失。

暂不优先：逐字卡拉 OK 动效、音频可视化、大量皮肤、重新造查词/卡片系统、考试题库。导入导出也不因竞品存在就列为优先需求。本轮没有需求访谈或使用数据，排序依据为日常阻碍程度与已有能力复用空间，不是统计结论。

后续实现验收需覆盖：主窗口最小化、锁定/解锁、断网重连、长句与最大字号、双屏断开、不同 DPI、重新启动；浏览器预览不能替代 Windows 原生穿透和窗口验证。本次只新增此调研文档，未实现功能或运行测试。
